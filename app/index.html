Mac и Windows, бесплатно

Одна программа для обеих систем. Новые версии ставятся сами — заново скачивать ничего не нужно.

Mac

• Mac на Apple M1 и новее (на Intel не работает)

• macOS 13 Ventura или новее

Первый запуск: «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть». Для заметки о зоне — разрешить «Запись экрана».

⊞ Windows

• Windows 10 или 11, 64-бит

• Права администратора (программа читает трафик игры)

SmartScreen: «Подробнее → Выполнить в любом случае». Для заметки о зоне нужен Microsoft Visual C++ Redistributable x64 (обычно уже стоит; если нет — программа подскажет).
